We are happy to announce Storm 2.0, the next major releases of Storm and stormpy.
<!--more-->

Version 2.0 is a major release with numerous breaking changes to the API, command-line options and behaviour of both Storm and stormpy.

Storm 2.0.0 brings (among others) the following highlights:

- Model checking results now carry upper and lower bounds, and sound solution bounds are available for DTMC/MDP model checking methods.
- Improved model checking of interval MDPs and interval DTMCs, including expected time and cumulative rewards.
- Added a native CVC5 SMT solver backend.
- Significantly faster sparse bisimulation and model building.
- Support for the WeakUntil (`W`) and Release (`R`) operators in properties.
- Certificate computation for reachability probabilities and expected rewards on MDPs.
- `--precision` is now interpreted as the distance between the bounds and the value (half-width) in interval iteration and the topological solver.
- A revised belief exploration for POMDPs, including the export of policies as finite-state controllers.
- Sequential convex programming (SCP) as a new method for parameter feasibility synthesis in `storm-pars`.

We refer to the [release notes of Storm](https://github.com/stormchecker/storm/releases/tag/2.0.0) for a complete list of all changes.

The [stormpy](https://stormchecker.github.io/stormpy/) Python bindings are also released in a new version 2.0.0 that comes with a major redesign of the Python API.
The public API is now split into subpackages such as `stormpy.models` or `stormpy.environments`, while the raw bindings moved to `stormpy.developer`.
Classes and functions are now generic over the value type (e.g., `stormpy.models.SparseDtmc[float]`), sound model checking is the default, and results return sound bounds.
Code written for stormpy 1.x needs to be adapted; the [migration helper](https://stormchecker.github.io/stormpy/changes_from_v1.html) lists all renamed symbols and enum values.
Stormpy 2.0.0 requires Python 3.11 or newer.
We refer to the [release notes of stormpy](https://github.com/stormchecker/stormpy/releases/tag/2.0.0) for all details.

You can get the new release of Storm either by building from [source]({{ '/documentation/obtain-storm/build.html' | relative_url }}), via the pre-built binaries from [Homebrew]({{ '/documentation/obtain-storm/homebrew.html' | relative_url }}), via the pre-built Debian packages attached to the [release](https://github.com/stormchecker/storm/releases/tag/2.0.0) or by using a [Docker container]({{ '/documentation/obtain-storm/docker.html' | relative_url }}).
You can obtain the stormpy Python package by simply executing `pip install stormpy`.
